## 4. Rangkuman Materi Workshop

### A. Prompt Engineering

Prompt Engineering adalah cara membuat instruksi yang jelas dan spesifik agar AI memberikan hasil sesuai kebutuhan.

Struktur prompt yang baik terdiri dari:
- **Role:** Peran AI.
- **Task:** Tugas yang diberikan.
- **Context:** Informasi pendukung.
- **Format:** Bentuk jawaban yang diinginkan.

### B. Git dan GitHub

- **Git:** Sistem untuk mencatat dan mengelola perubahan file atau proyek.
- **GitHub:** Platform online untuk menyimpan repository Git dan mendukung kolaborasi.

Beberapa istilah penting:
- **Repository:** Tempat penyimpanan proyek.
- **Commit:** Catatan perubahan proyek.
- **Branch:** Cabang pengembangan proyek.
- **Pull Request:** Pengajuan perubahan untuk ditinjau dan digabungkan.

### C. Perintah Dasar Git

```bash
git init
git add .
git commit -m "Initial commit"
git push origin main
git pull origin main
git clone URL_REPOSITORY
```

Perintah tersebut digunakan untuk mengelola perubahan dan menghubungkan proyek dengan GitHub.
